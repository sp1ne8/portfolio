## Исправления 17 октября

- Логотип: отсутствует входное размытие и фильтр на родителе. Hover/focus использует translate3d на 3px и переход 460 мс; will-change ограничен двумя небольшими SVG на устройствах с мышью.
- Проекты: изображение не прокручивается внутри рамки при hover/focus. Появление рамки завершается один раз, затем observer отключается для этого элемента. На мобильных ширинах рамка не сдвигается.
- Скругление превью 12px — прямое пожелание пользователя, исключение из радиусов 0/999.
- Area: новый реальный снимок демо без раскрытого меню и полупрозрачного текста. Размеры изображения прописаны; загрузка lazy, декодирование async.
- При смене размера/настроек анимации содержимое остаётся доступным. Нет обработчиков wheel/touchmove, перехвата скролла или постоянно работающего animation loop.
- Проверены мобильное меню, Escape, переход к проектам, PageDown через обе работы, RU/EN, фокус превью, отсутствие горизонтального переполнения.
- Проверка сделана в Chromium с мобильными размерами окна. FPS и поведение на физическом телефоне не измерялись.
