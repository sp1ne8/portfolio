# sp1ne — portfolio

Двуязычное портфолио для заказчиков на сайты и интерфейсы. HTML, CSS и JavaScript без сборщика. В демонстрационных сайтах используется локальная копия Three.js для объёмных объектов; CDN и установка зависимостей не нужны.

## Файлы

- `dist/index.html` — разметка и русский текст без JavaScript.
- `dist/styles.css` — стили, адаптация, анимации и reduced-motion.
- `dist/script.js` — RU/EN, меню, анимации появления.
- `dist/assets/` — изображения, SVG-знак, favicon и локальные шрифты.
- `ASSETS.md` — происхождение изображений и промпты.
- `ACCEPTANCE.md` — проверка AI-RULES §9.

## Просмотр

Из этой папки:

```sh
npm run dev
```

Нужен установленный Node.js с npm. Откройте `http://localhost:4173/`. Сборка и установка зависимостей не нужны. После правок обновите страницу браузера. Остановка сервера — `Ctrl+C`. Для любого статического хостинга используйте содержимое `dist/`.

## Контент

Демонстрационные сайты доступны по адресам `/demos/garage/index.html` и `/demos/coffee/index.html`. У NORTHLINE есть выбор услуги, FAQ и форма подготовки запроса с копированием. Форма работает локально и не отправляет данные. У STILL — выбор напитка, меню с категориями и раздел визита. Оба бизнеса вымышлены, что указано на страницах.

Кофейное зерно и его движение создаются в `dist/demos/coffee/bean-scene.js`. У STILL есть две сцены с зерном; выбор напитка меняет крупную типографическую композицию. Чашка из интерфейса удалена. Автосервис использует `dist/demos/shared/suspension-model.js` и `product-scene.js` для подвески и тормозов. Сцены загружаются по мере приближения к экрану и прекращают отрисовку в покое. Прокрутка нативная, движение сглаживается по времени, есть поддержка reduced-motion. Растровых заглушек у 3D нет: первый отрисованный кадр появляется плавно. Без WebGL остаются текст, меню и формы, область объекта пустая. Лицензия Three.js находится рядом с библиотекой в `dist/demos/shared/vendor/THREE-LICENSE.txt`.

Переводы находятся в объекте `translations` в `dist/script.js`. Русский текст также записан в HTML для отображения без JavaScript. После изменения русского контента обновите оба файла.

`?lang=en` открывает английскую версию. Язык сохраняется в localStorage; если хранилище недоступно, переключатель продолжает работать.
