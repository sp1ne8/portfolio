# sp1ne — portfolio

Двуязычное портфолио для заказчиков на сайты и интерфейсы. Чистые HTML, CSS и JavaScript, без сборщика и внешних библиотек.

## Файлы

- `dist/index.html` — разметка и русский текст без JavaScript.
- `dist/styles.css` — стили, адаптация, анимации и reduced-motion.
- `dist/script.js` — RU/EN, меню, анимации появления.
- `dist/assets/` — изображения, SVG-знак, favicon и локальные шрифты.
- `ASSETS.md` — происхождение изображений и промпты.
- `ACCEPTANCE.md` — проверка AI-RULES §9.

## Просмотр

Из этой папки:

```sh
python -m http.server 4173 --directory dist
```

Откройте `http://localhost:4173/`. Сборка и установка зависимостей не нужны. Для любого статического хостинга используйте содержимое `dist/`.

## Контент

Переводы находятся в объекте `translations` в `dist/script.js`. Русский текст также записан в HTML для отображения без JavaScript. После изменения русского контента обновите оба файла.

`?lang=en` открывает английскую версию. Язык сохраняется в localStorage; если хранилище недоступно, переключатель продолжает работать.
