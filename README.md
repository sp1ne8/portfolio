# sp1ne — портфолио

Статический сайт без сборки. Для запуска нужен Node.js:

```sh
npm run dev
```

Откройте http://127.0.0.1:4173/. Порт можно изменить: `npm run dev -- 4189`.

Сайт кофейни «Пауза», Future Tech, Area и HYDRA находятся в `dist/demos/` и открываются через портфолио, без GitHub Pages. Attention доступен по адресу `dist/demos/attention/`: сайт, локальный веб-планировщик и APK. Облачная синхронизация требует настройки Supabase в конфигурации проекта.

Для публикации на статическом хостинге используется содержимое `dist/`. Файлы, отправляемые браузеру посетителя, могут быть просмотрены через инструменты разработчика. Чтобы не публиковать исходники на GitHub, используйте приватный репозиторий или загрузку файлов непосредственно на хостинг.
