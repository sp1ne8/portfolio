# sp1ne — Developer Portfolio

A personal portfolio showcasing my work in frontend development and AI-assisted projects.

**Website:** [sp1ne.tech](https://sp1ne.tech)

## Selected projects

- **Future Tech** — a technology website built from a Figma design.
- **Area** — an analytics landing page built from a Figma design.
- **Attention** — a focus and planning app, with an Android download and a browser-based planner.
- **HYDRA** — a GTA 5 RP materials website. The portfolio demo shows its public-facing pages.

## Run locally

You need Node.js installed. From the repository folder, run:

```bash
npm run dev
```

Open [http://127.0.0.1:4173](http://127.0.0.1:4173). To use another port, run `npm run dev -- 4189`.

The portfolio is a static site; its files are in `dist/`. It supports English and Russian. The Attention web planner works locally; cloud sign-in and synchronization require a configured Supabase project.
